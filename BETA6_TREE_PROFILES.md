# Beta 6 regional trees and size modes

## Tree-size selector

Beta 6 uses four simple labels:

1. **Standard (Lidar)** — the existing Legacy LiDAR size calculation.
2. **Heroic** — the established Heroic population calibration.
3. **Epic** — exactly `1.20 × Heroic`.
4. **Mythic** — exactly `1.80 × Heroic`.

For built-in Designer themes, Epic and Mythic multiply the full Heroic X/Y/Z output ranges. For regional profiles, they multiply the donor-calibrated X/Y/Z result. Heroic remains the default.

## Pacific Northwest

The **Pacific Northwest** profile is calibrated from the finished `Rainier 18 holes - Finished.course`, whose in-course name is `Mount Rainier 1931 (L)`.

The analysis retained 45 terrain-aligned tree placements from 66 SpeedTree objects and excluded 21 vertically displaced scenery/massing placements. The enabled seven-asset pool is conifer-oriented and uses Alaska cedar, generic conifer, and Scots pine assets as visual analogs rather than literal botanical claims.

The profile also applies the donor's root Designer theme and its bunker/turf/terrain material configuration.
