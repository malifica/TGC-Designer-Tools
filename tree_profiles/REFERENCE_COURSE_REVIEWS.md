# Beta 5 reference-course review log

This log records finished-course references that were inspected for real-life tree
profile calibration but were not necessarily accepted into a theme.

## Royal West Norfolk (Brancaster)

Location: Brancaster, Norfolk, England.

Decision: **not suitable as a tree-profile calibration source**.

The uploaded course contains 117 actual SpeedTree tree placements, but only **1**
is natural / terrain-aligned under the Beta 5 reference filter. The other **116**
are vertically manipulated scenery-massing objects. This matches the real course's
very open coastal links character: dunes, salt marsh and scrub are much more
important to its landscape identity than specimen trees.

The file may be useful later if Beta 5 grows a separate British coastal-links
**foliage/scrub** profile system, but it should not affect tree prefab weights or
tree scale distributions.

## The Olde Course at Loveland

Uploaded name: `Old'e Course (Reverse)(L)`

Location match: The Olde Course at Loveland, Loveland, Colorado.

Decision: **geographically useful, but insufficient natural tree samples for
theme calibration from this file alone**.

The uploaded course contains 141 actual SpeedTree tree placements. Only **12** are
natural / terrain-aligned; **129** are vertically manipulated scenery-massing
objects. The surviving natural sample is mostly Red Maple with two Green Ash
instances.

The broader planted asset family in the file—maple, locust, elm, ash, sycamore
and oak—is visually plausible for a mature irrigated northern Colorado / Front
Range parkland course, but the massing-heavy construction makes the prefab
frequencies and scales unsuitable for direct calibration.

Provisional future theme name: **Colorado Front Range Parkland**.

Wait for at least one reference course with 25 or more natural / terrain-aligned
specimen trees before creating/enabling that profile.
