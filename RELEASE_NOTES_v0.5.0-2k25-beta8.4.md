# TGC Designer Tools 2K25 — Beta 8.4

- **Graduated Background** is selectable beside **Background Scale**. Enabling it overrides the manual scale; switching it off restores the manual setting.
- Red-mask background terrain uses three Brush 10 sizes, written from the outside in: **64 m**, **32 m**, and **four times the effective main brush scale** directly at the seam. Main terrain is written last.
- A 72/1 main brush gets a 10/4 seam. A 10/3 main brush gets a 10/12 seam. Background centers follow measured elevations on the red side of the saved mask.
- Includes Beta 8.3's open rough and water island handling.

Windows executable: `tgc_gui_2k25_beta8_4.exe`.
